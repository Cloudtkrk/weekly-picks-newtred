# Kalodataを画面から取得して週次更新する手順

エクスポート(ダウンロード)機能を使わず、Kalodataの画面に出ている表を読み取って
`input/` に置くための手順。**Claude in Chrome 拡張が使えるセッションで実行すること**
(claude.ai のリモートセッションはブラウザ操作ツールを持たず、`kalodata.com` への
通信もネットワークポリシーで遮断されるため実行できない)。

## 出力するファイル

`input/` に**3〜4ファイル**を置く。拡張子は `.csv` でよい (`.xlsx` も可)。
ファイル名は `--auto` の判別に使うので**この命名を必ず守る**:

| ファイル名 | 中身 |
|---|---|
| `Kalodata_Product_<任意>_JP.csv` | 売れ筋 (上位150件) |
| `Kalodata_Product_<任意>_JP.csv` | 新商品 (上位100件) |
| `Kalodata_Video_<任意>_JP.csv` | 動画 (上位200件) |
| `Kalodata_Video_<任意>_JP.csv` | 動画・フォロワー少 (上位100件、任意) |

`--auto` の判別ルール:

- 商品2ファイル … 「アップロード時間」が**全行45日以内**の方を新商品、もう一方を売れ筋とみなす
- 動画2ファイル … 行数が多い方を通常動画。**同数のとき**はGMV中央値が高い方を通常動画とする
- 判別できない場合はエラーで停止する (`--products` / `--new` / `--videos` / `--videos-small` で明示指定も可)

文字コードは UTF-8 (BOM付きも可) か CP932。1行目がヘッダー。

## 収集条件 (画面のフィルタ設定)

| ファイル | 条件 |
|---|---|
| 商品(売れ筋) 上位150件 | 過去30日 / 販売経路=連携クリエイター / アフィリ対応✔ / 評価4.0+ / 売上500万円+ / 売上高降順 |
| 商品(新商品) 上位100件 | 過去30日 / 販売経路=連携クリエイター / **掲載30日以内** / アフィリ対応✔ / **売上50万円+** / 成長率降順 |
| 動画 上位200件 | **過去7日** / AI生成動画=いいえ / 売上高降順 / フィルタ他なし |
| 動画(フォロワー少) 上位100件 | **過去7日** / クリエイターフォロワー数の少ない層に絞り込み / 売上高降順 |

## 必要な列 (列名が一致していれば順序は自由)

列名は `weekly_picks.find_col` が候補名から探すので、**下記のいずれかの表記**であればよい。
`取引金額` だけは前方一致で特定するため、**`平均取引金額` と紛れない列名**にすること。

### 商品ファイル

| 用途 | 列名 (候補) | 必須 |
|---|---|---|
| 商品名 | `商品名称` / `商品名` / `商品情報` | **必須** |
| 30日売上 (合計GMV) | `取引金額 (円)` — 先頭が「取引金額」 | **必須** |
| 成長率 | `売上高成長率` / `成長率` | 新商品の並び順・除外に使用 |
| 販売数 | `販売数` / `販売件数` | |
| 評価 | `商品レビュー` / `商品評価` / `評価` | |
| 単価 | `平均取引金額 (円)` / `価格(¥)` / `平均販売価格` | カードに表示 |
| 報酬率 | `報酬率` / `コミッション` | **必須** (3%以下とアフィリ非対応「-」を除外) |
| 参画クリエイター数 | `クリエイター数` | バッジ・並び順に使用 |
| 成立率 | `クリエイター取引成立率` | バッジ・並び順に使用 |
| 掲載日 | `アップロード時間` / `掲載日` | **必須** (売れ筋/新商品の自動判別と参画ペースに使用) |
| カテゴリ | `カテゴリー` / `カテゴリ` | 5ジャンル分類に使用 |
| LIVE売上 | `ライブ取引金額 (円)` | LIVE向き/動画向きタグに使用 |
| 動画売上 | `動画取引金額 (円)` | 同上 |
| 商品URL | `TikTokリンク` | **必須** (商品IDの取得元。案件リストとの突合に使う) |
| Kalodata詳細 | `Kalodata詳細リンク` | |

### 動画ファイル

| 用途 | 列名 (候補) | 必須 |
|---|---|---|
| 商品名 | `商品名` | **必須** (商品ファイルと突合する) |
| 動画売上 | `取引金額 (円)` — 先頭が「取引金額」 | **必須** |
| 投稿日 | `投稿日` | |
| GPM | `1000視聴回数取引金額 (円)` — 「1000視聴」を含む | |
| 広告視聴率 | `広告視聴率` | オーガニック判定に使用 |
| 視聴回数 | `視聴回数` | |

## 値の書式

パーサが吸収するので神経質にならなくてよい。

- 金額 … `1,234,567` / `¥1,234,567` / `123万円` いずれも可 (`parse_money`)
- 率 … `40%` / `40` / `0.4` ではなく**パーセント表記**で (`parse_pct`)
- 報酬率のアフィリ非対応は `-` のまま入れる (除外判定に使う)
- 日付 … `2026-08-11` 等、pandasが読める形式
- **数値を推測で埋めないこと**。取れなかったセルは空のままにする
  (CLAUDE.md「してはいけないこと」に該当する)

## 取り込み後

1. `input/` の古いファイルを消して新しい3〜4ファイルを置く
2. コミット&プッシュ → Actionsがプレビューを生成
3. プレビューを確認し、OKなら `publish:` で始まるコミットをプッシュして本公開

## 注意

- 画面は1ページあたりの表示件数が限られるので、**ページ送りしながら全件集める**こと。
  件数が足りないと売れ筋/新商品の判別や各ジャンル上位10件の選抜がずれる
- 取得元がエクスポートでも画面でも、**列名さえ揃っていれば生成結果は同一**になる
  (9/7分のエクスポートをCSVに変換して検証済み。売れ筋・新商品とも完全一致)
